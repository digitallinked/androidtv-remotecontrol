# Demo video script (for App Review and Play's App access)

A 60–90 second video showing the app controlling a real TV, for `{{DEMO_VIDEO_URL}}` (`apple-review-notes.md`, `play-declarations.md`). Recorded by the owner on real devices **[owner]** **[device]**; Claude doesn't record or host it.

## Setup

- **Phone:** an iPhone with the release build (TestFlight) freshly installed, so onboarding and the Local Network prompt appear. Free version (not Premium), so the paywall shows plans. Do Not Disturb on, so no notifications appear.
- **TV:** an Android TV or Google TV on the same Wi-Fi, on its home screen. **Keep third-party content off the TV screen:** stay on the home screen and system screens (search box, settings); don't open a streaming app or play any video, and if the home screen shows rows of recommended shows, pick a moment or a profile where they're plain, or frame the TV so the row isn't readable.
- **Recording:** the phone's own screen recording for the phone, plus a second camera on the TV; edit them side by side (phone left, TV right), or film both in one steady shot with the phone held in front of the TV. No music with lyrics; captions are optional.
- **TV name:** rename the TV to something neutral first (for example "Living Room TV"), so no personal name appears.
- Don't show the pairing code on screen for longer than needed; it is single-use, so it is harmless, but keep it short.
