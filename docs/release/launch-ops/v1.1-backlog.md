# v1.1 backlog

Everything deliberately left out of v1.0, with why it matters and what it waits for. Groomed at the end of Phase 9 (2026-11-03) from the master plan's v1.1 list, Ruling P9-R16, the device-run outcomes decisions #10 and #23 wait for, and every item Phases 8 and 9 deferred.

- **Size:** S = up to a day, M = a few days, L = a week or more, including tests and store-form updates.
- **Ids** (`V11-nn`) are stable: refer to them in plans and `status.md`, and never reuse one. A dropped item keeps its row with "Dropped: <reason>".
- **Nothing here may be claimed in store copy** until it ships (Ruling P9-R13).
- **Order within a group is the suggested order.** The groups themselves aren't ordered: the device run (group B) decides a lot, and the owner decides between features (group A).

## E. Developer CLI (`packages/atv_remote`, from the Task 9.7 review)

None of these touches the app; the CLI is a developer tool.

| Id | Item | Why | Size | Depends on |
|---|---|---|---|---|
| V11-24 | **Per-process temp name for `identity.json`** (for example `identity.json.<pid>.tmp`). | Two CLI processes creating the identity at once share one `.tmp`: their writes can interleave and the loser's cleanup throws (9.7 review minor 1). | S | None. |
| V11-25 | **`chmod 600` the CLI identity on POSIX.** | `~/.atv_cli/identity.json` holds a private key and is created with the umask default (usually 0644, the folder 0755), so other local users can read it; `dart:io` has no chmod, so run `chmod 600`/`700` off Windows. | S | None. |
| V11-26 | **Delete the `.tmp` when the rename fallback rethrows.** | When the rename fails and no `identity.json` exists, the `.tmp` (holding the private key) stays behind; also assert it is gone in `a_failed_write_never_leaves_a_partial_identity`. | S | None. |
| V11-27 | **A sharper `hold` drop test:** a per-test timeout and a comment naming the path it proves (the `RemoteClosed` event, not the post-interrupt check). | Without the post-interrupt `isReady` check the test only fails through the 30 s default timeout, and it proves the event path, not that check (9.7 review minor 6). | S | None. |
